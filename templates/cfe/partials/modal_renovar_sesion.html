Renovar sesión MiEspacio

{% if estado_sesion.sesion_activa %} Sesión actualmente activa {% else %} Sesión expirada o no configurada {% endif %}

La descarga de PDF desde MiEspacio requiere una sesión válida. Cuando expira, hay que resolver el CAPTCHA una vez. Con el lanzador local puedes hacerlo tú mismo desde tu PC, sin esperar al administrador.

{% if not estado_sesion.renovacion_habilitada %}
Renovación no habilitada todavía. Pide al equipo de sistemas que genere el token del lanzador en Admin > Configuración Global > Recibos CFE.
{% endif %}

Pasos

  1. Abre el lanzador Renovar sesión CFE en tu PC.
  2. Se abrirá Microsoft Edge en la página de MiEspacio.
  3. Inicia sesión y resuelve el CAPTCHA (único paso manual).
  4. No cierres la ventana: el lanzador detecta el login y sube la sesión solo.
  5. Cuando veas "Sesión renovada ✓", listo. Cierra y recarga esta página.

¿No tienes el lanzador? Solicítalo al equipo de sistemas junto con el token de acceso.
