Roles y Permisos

Existen dos niveles de acceso independientes: el rol de sistema (qué puede hacer el usuario en toda la plataforma) y el rol de módulo (qué puede hacer dentro de cada módulo específico).

Rol de sistema

USER

Usuario estándar

Puede crear y editar sus propios registros dentro de los módulos donde tiene acceso. No puede reasignar ni ver registros de otros usuarios.

MANAGER

Gestor de equipo

Puede editar, reasignar y gestionar registros de su equipo. Equivale a rol de módulo "editor" en los módulos donde es Manager.

ADMIN

Administrador

Control total de la plataforma. Bypasea los controles de módulo — tiene acceso a todo sin necesitar permisos individuales de módulo.

Rol de módulo

Se asigna por separado en cada módulo. Un usuario puede ser viewer en Compras y admin en Simulación.

Viewer

Solo lectura. Puede consultar registros pero no crear, editar ni eliminar.

Editor

Puede crear y editar sus propios registros. En algunos módulos puede ver y editar los de su equipo.

Admin

Control total del módulo: gestión completa de todos los registros, configuración y acciones administrativas.

Rol organizacional

Define autoridad transversal entre departamentos. Solo uno por usuario. No reemplaza el rol de sistema ni de módulo.

Jefe Comercial

Autoridad sobre el equipo comercial.

Jefe de Ingeniería

Autoridad sobre el equipo de ingeniería.

Jefe de Construcción

Autoridad sobre el equipo de construcción.

Director

Visibilidad y autoridad global.

Gestión de Usuarios

Guía rápida para configurar un usuario nuevo o actualizar uno existente.

1

El usuario inicia sesión por primera vez

Se crea automáticamente con Microsoft Azure AD. Aparece en la tabla con rol USER y sin módulos asignados.

2

Asignar rol de sistema

En el modal de edición, Tab "General". Usar USER para operadores, MANAGER para jefes de área, ADMIN solo para el equipo de sistemas.

3

Asignar módulos y niveles de acceso

Tab "Módulos". Asignar solo los módulos que el usuario necesita. El módulo de inicio se actualiza automáticamente.

4

Configurar opciones avanzadas (si aplica)

Tab "Avanzado": rol organizacional para jefes de área, y flags de asignación para usuarios que participan en simulaciones o levantamientos fuera de su departamento.

Desactivar vs Eliminar

La plataforma usa soft delete. Desactivar un usuario oculta su acceso pero conserva todos sus registros históricos. No existe eliminación permanente desde la interfaz.
