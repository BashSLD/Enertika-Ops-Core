Flujo Comercial

1. Registro de Oportunidad

El proceso inicia cuando detectas una necesidad. Usa el botón + Nuevo.

Elige bien la fecha requerida:

Sé realista. Si pides todo "para mañana", Simulación no podrá priorizar lo verdaderamente urgente.

Requisitos mínimos:

Recibo CFE (PDF), Ubicación (Maps), Nombre del Cliente.

2. Seguimiento y Negociación

Una vez enviada, Simulación calcula un Deadline (SLA).

¿La fecha calculada no te sirve?
Contacta al Manager de Simulación para negociar una nueva fecha. Si la aprueban, esta aparecerá como "SLA Negociado".

3. Recepción de Oferta

Recibirás una notificación cuando Simulación termine (Estado: Entregado).

Descarga la propuesta, revísala y preséntala al cliente.

4. Cierre

Es vital cerrar el ciclo en el sistema.

💬 Comunicación y Adjuntos

Cada oportunidad cuenta con un canal de comunicación centralizado para mantener todo el contexto en un solo lugar.

Historial de Comentarios

Usa el botón 💬 Ver/Enviar Comentarios en la tarjeta o detalle.

  • Queda registro inalterable de fecha y hora.
  • Visible para todos los involucrados (Comercial, Ingeniería, etc.).
  • Evita hilos de correo dispersos.
Archivos Adjuntos

Puedes subir archivos relevantes (planos, recibos, correos) directamente en el hilo de comentarios.

  • Usa el icono de clip 📎 dentro del modal de comentarios.
  • Soporta múltiples archivos.
  • Los archivos se guardan seguros y organizados.

Tipos de Solicitud y Registro

📝 Pre-oferta

Estimación rápida o presupuesto preliminar.

Menor precisión, menor tiempo de respuesta.

🎯 Oferta Final

Propuesta definitiva con ingeniería de detalle básica.

Requiere información completa (Levantamiento).

⚖️ Licitación

Concurso formal.

Marca la casilla de selección "Licitación" para alertar prioridad.

🔄 Actualización

Modificar una oferta previa (V1 -> V2).

Tambien puedes usar la opción "Solicitud Especial" para ligarla a un hilo anterior.

Tipos de Registro (Formularios)

  • Nuevo Registro: El estándar. Envía correo automático a Simulación.
  • Extraordinario: Solo Managers Para registrar cosas que "ya pasaron". No envía correos de notificación.
  • Solicitud Especial: Busca un folio existente para agregar una nueva versión (Homologación).

📅 Fechas Importantes

Fecha Requerida

Indica fecha cercana a cuándo presentas al cliente.
¡Ojo! No pongas fechas irreales, o perderás credibilidad.

Entrega SLA

La fecha que el sistema calcula que Simulación debería tardar.

SLA Negociado

Si Simulación se compromete a una fecha diferente (antes o después del SLA), aparecerá aquí. Esta es tu fecha real de entrega.
