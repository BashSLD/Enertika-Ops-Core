Gestión de Gastos y Compras

1

Carga de Comprobantes

Sube tus tickets o comprobantes de pago (PDF) al sistema.

  • El sistema lee automáticamente: Fecha, Monto, Beneficiario.
  • Detecta duplicados para evitar errores.
2

Clasificación

Completa la información faltante:

Proyecto: ¿A dónde se carga el gasto?
Categoría: Viáticos, Material, Herramienta, etc.
3

Facturación (Match XML)

Sube los XMLs (CFDI) que te envían los proveedores.

El sistema vinculará automáticamente el XML con el PDF del ticket correspondiente.

Status Final: FACTURADO

Conciliación Automática

¡Ahorra tiempo! No necesitas buscar manualment qué factura corresponde a qué ticket.

¿Cómo funciona?

Cuando subes un paquete de XMLs (puedes arrastrar 50 a la vez), el sistema analiza cada uno y busca en la base de datos un comprobante que coincida en:

RFC Emisor
+
Fecha +/- 3 días
+
Monto Exacto
Match Perfecto (Automático)

Si encuentra uno solo que coincide, lo vincula automáticamente. El estatus cambia a "FACTURADO" y los items de la factura se guardan.

Match Ambiguo (Manual)

Si hay varios tickets con el mismo monto y proveedor, el sistema te pedirá que elijas cuál es el correcto.
