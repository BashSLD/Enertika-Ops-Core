Empleados e Identificadores

Cada empleado tiene tres tipos de ID en el sistema. Entender cuál es cuál evita confusiones al configurar accesos o resolver discrepancias de asistencia.

ID Sistema

UUID interno de Enertika Core

Generado automáticamente al crear el usuario. No se muestra en pantalla. Es la llave principal de todos los registros internos.

Número de Empleado

Clave de nómina / IMSS

Se registra manualmente en el perfil del empleado. Es un dato interno de RH y no se usa para mapear checadas de BioTime.

Código BioTime (emp_code)

ID en el dispositivo de checado

Asignado por BioTime PRO. Se sincroniza automaticamente cuando el correo de BioTime coincide con el correo corporativo en ECO.

¿De dónde vienen los datos del empleado?

🏢
Microsoft Azure AD

Se sincroniza automáticamente al iniciar sesión. Solo llena campos vacíos — no sobreescribe datos ya registrados.

  • ✓ Nombre completo
  • ✓ Correo corporativo
  • ✓ Departamento
  • ✓ Puesto (job title)
⏱️
BioTime PRO

Sincronización periódica automática. También puede iniciarse manualmente desde Admin.

  • ✓ Checadas (entrada / salida)
  • ✓ Codigo BioTime (emp_code)
  • ✓ Correo para mapeo automatico

¿Cómo se vinculan las checadas con el empleado?

1°
Correo corporativo

El correo de BioTime se normaliza y se compara contra el correo activo en ECO. Si coincide de forma unica, se crea el mapeo.

2°
Codigo BioTime sincronizado

Despues del match por correo, ECO guarda el emp_code en datos laborales y lo muestra como solo lectura en RRHH -> Empleados.

3°
Excepciones visibles

Si no hay correo, no coincide o esta duplicado, la checada queda sin usuario y aparece en RRHH -> Asistencia.

Si las checadas de un empleado no se reflejan: corrige el correo del empleado en BioTime o ECO y vuelve a sincronizar. No uses el numero de empleado como sustituto del codigo BioTime.

El reporte Excel de asistencia agrega una hoja Checadas sin mapear cuando existen codigos BioTime sin empleado asociado en el rango.

Configuración de Horarios

Los horarios definen cuándo se espera que un empleado esté presente. El sistema los usa para calcular asistencia correctamente.

Estructura: Sucursal → Horario → Días

Cada sucursal puede tener múltiples horarios activos (ej: turno matutino y turno nocturno). Cada horario define los días de la semana y la hora de entrada/salida para cada uno.

🌙

¿Qué es "Cruza medianoche"?

Es un indicador automático para horarios que inician un día y terminan al siguiente. El sistema lo calcula comparando hora de entrada y hora de salida.

Ejemplo: horario que termina al día siguiente

Lunes
22:00 → 06:00 mar
Detectado automáticamente
Martes
Sin trabajo
(el empleado descansa)
Miércoles
22:00 → 06:00 jue
Detectado automáticamente

La salida de las 06:00 del martes pertenece al turno del lunes. El día seleccionado siempre es el día en que inicia la jornada.

→ Si la salida es menor que la entrada, el sistema marca automáticamente que cruza medianoche.
→ Si la salida es mayor que la entrada, el horario no cruza medianoche.
→ Si entrada y salida son iguales, el horario es inválido. Las salidas muy tarde o en madrugada se manejan con la ventana después de salida.

Los horarios se configuran en RRHH → Admin → Horarios. Un horario desactivado no se usa para calcular asistencia nueva, pero conserva el histórico ya calculado.

Registro de Asistencia

La asistencia se calcula a partir de las checadas de BioTime combinadas con el horario asignado al empleado.

1

Sincronización automática con BioTime

El sistema descarga periodicamente empleados y checadas. Primero crea mappings por correo; despues guarda cada checada con su usuario cuando el emp_code ya esta mapeado.

2

Cálculo diario por empleado

Para cada día y empleado, el sistema busca la checada de entrada y salida dentro de la ventana del horario configurado. Si el turno cruza medianoche, la ventana se extiende al día siguiente.

3

Resultado visible en RRHH → Asistencia

Se muestra la hora real de entrada, salida, horas trabajadas, horas extra y estado del dia. Si hay checadas sin usuario, aparece un aviso por codigo BioTime.

Acciones disponibles

Importar histórico

Disponible en Admin -> Configuracion BioTime -> Importar historico. Permite descargar checadas de un rango pasado; tambien intenta mapear empleados por correo antes de recalcular.

Recalcular asistencia

Si se corrige un horario o se importan checadas retroactivas, el recalculo actualiza los registros de asistencia sin borrar el historico de checadas.

Puede ser por alguna de estas razones:

  • El correo en BioTime no coincide con el correo activo en ECO.
  • El correo esta duplicado o vacio en alguno de los sistemas.
  • El dispositivo BioTime aún no sincronizó esas checadas al servidor.
  • La checada está fuera de la ventana del horario configurado.
Sin horario, el sistema no puede calcular la asistencia diaria aunque reciba las checadas. Las checadas se guardan en bruto. Asigna un horario en RRHH -> Admin -> Horarios y luego recalcula el periodo.

Flujo de Aprobación de Vacaciones

Las solicitudes de ausencia siguen una jerarquía de aprobación configurable por empleado.

🎯

Aprobador designado

Se configura directamente en el perfil del empleado (campo "Aprobador de vacaciones"). Tiene prioridad absoluta sobre los jefes inmediatos.

Úsalo cuando el aprobador de vacaciones es distinto al jefe directo (ej: un gerente regional, RH, etc.).

🏗️

Jefe inmediato

Se configura en el perfil del empleado (campo "Jefe inmediato"). Se usa cuando no hay aprobador designado. Puede haber más de uno.

Todos los jefes inmediatos reciben la notificación y cualquiera puede aprobar o rechazar.

¿A quién le llegan los correos?

Al solicitar
Notificación al aprobador designado (si existe) o a los jefes inmediatos. RH no recibe este correo.
Al aprobar
TO: el solicitante — CC: equipo RRHH (editor / admin) — CCO: correos adicionales configurados en Admin. Se adjunta el PDF aprobado.
Al rechazar
TO: el solicitante con el motivo de rechazo — CC: equipo RRHH (editor / admin) — CCO: correos configurados en Admin.

Para agregar correos CCO (copia oculta)

Ve a Admin → Configuración General → Notificaciones de Vacaciones. Puedes poner varios correos separados por coma.
